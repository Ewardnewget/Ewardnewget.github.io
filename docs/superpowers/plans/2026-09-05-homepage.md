# Researcher Homepage Implementation Plan

> For agentic workers: execute the approved design task by task; verify each result.

**Goal:** Create a maintainable academic homepage based only on supplied biographical sources.
**Architecture:** A project-level Hugo homepage overrides only the landing page; existing HugoBlox modules remain pinned. YAML/Markdown are the source of truth. Small local CSS and JS enhance the static page.
**Tech Stack:** Hugo 0.161.1, existing HugoBlox modules, Go templates, HTML/CSS/JavaScript, YAML/Markdown, GitHub Actions.
**Spec:** docs/superpowers/specs/2026-09-05-homepage-design.md

## Global constraints
- Do not modify remote main; writing the feature branch was rejected with HTTP 403.
- No raw CV, sensitive personal details, unknown identifiers/dates or unsupported publication status.
- No frontend framework, external fonts, tracking, Google Scholar scraping or fabricated links.
- Core content must work without JS; generated pages must contain no starter examples.

## Task 1: Source records
Files: data/authors/me.yaml, data/publications.yaml, data/funding.yaml, data/records.yaml, site-content/_index.md; tests/test_content.py.
- Write assertions for identity, nonempty publications, allowed statuses, unique IDs, exact seed funding and author ordering.
- Run `python -m unittest discover -s tests -p 'test_content.py' -v`; confirm missing records fail before creating them.
- Transcribe source records, keeping under-review entries separate; run the same tests again.

## Task 2: Static presentation
Files: layouts/home.html, layouts/_partials/researcher/*.html, site-static/css/researcher.css, site-static/js/researcher.js, site-static/images/portrait.jpg.
- Write generated-HTML tests before rendering. Assert landmarks, one h1, real image, headings, no template placeholders, optional-link behavior, author emphasis and no original CV.
- Implement semantic templates with escaped fields and local assets. Generate an offline preview from the same Go templates for inspection (not a substitute for a full Hugo build).
- Run `python -m unittest discover -s tests -p 'test_site.py' -v` against the preview and check in a browser at desktop/mobile widths and without JS.

## Task 3: Integration and maintenance
Files: config/_default/{hugo,params,menus,languages,module}.yaml, go.mod, hugoblox.yaml, package.json, .github/workflows/{build,deploy}.yml, README.md, docs/CONTENT_SOURCES.md, scripts/check_site.py.
- Preserve pinned HugoBlox module revisions and Hugo/Node setup. Validate PRs without requiring Pages configuration; deploy only from main.
- Run source/content checks before build and generated-site checks after build; attach a PR preview artifact, never auto-deploy PRs.
- Document exact editing locations, copying paper/funding templates, clean-branch installation, publishing steps and rollback.
- Verify YAML, JavaScript syntax, template output, asset links, privacy, browser behavior and the guarded overlay application. Report full-Hugo and remote checks as blocked when they cannot be executed.
